Native Game Library 0.2.0 - Windows 10/11 + Linux portable package
===================================================================

WINDOWS 10 / 11
----------------
1. Extract the whole "windows" folder anywhere (e.g. Desktop).
2. Double-click windows\NativeGameLibrary\NativeGameLibrary.exe.
   - No Python installation and no administrator rights are needed.
   - The exe is unsigned, so Windows SmartScreen may warn on first run:
     choose "More info" then "Run anyway". That warning is expected for
     unsigned builds, exactly as for the project's CI releases.
   - Data is stored under %APPDATA%\NativeGameLibrary and
     %LOCALAPPDATA%\NativeGameLibrary.

LINUX (GTK 3)
--------------
1. Extract the whole "linux" folder anywhere.
2. Run:  cd linux/NativeGameLibrary-0.2.0-linux-x86_64 && ./run.sh
   - Requires python3 (3.10+), gtk+3, python3-gobject, python3-cairo and
     gdk-pixbuf (per-distro package names are in README.md):
       Debian/Ubuntu: sudo apt install python3-gi python3-gi-cairo gir1.2-gtk-3.0
       Fedora:        sudo dnf install python3-gobject gtk3
       Void:          sudo xbps-install -Su python3 gtk+3 python3-gobject python3-cairo gdk-pixbuf
3. Optional desktop entry (per-user, no root): ./packaging/install-desktop.sh

NOTES
-----
- The Windows build was produced with PyInstaller (the project's own
  packaging/windows/NativeGameLibrary.spec) under Wine on Linux and
  smoke-tested: it starts and stays running. The project's CI performs
  the authoritative smoke test on real Windows.
- Nothing is executed automatically; the app asks for explicit
  confirmation before launching any downloaded file.
